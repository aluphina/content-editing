# Polza.ai: генерация медиа

Утилита: `tools/polza/polza` (из корня репозитория). Ключ берётся только из переменной окружения `POLZA_AI_API_KEY`; в облачной сессии его подставляет прокси для хоста `api.polza.ai`. Ключ никогда не печатать, не логировать и не коммитить.

## Команды

```bash
tools/polza/polza balance                               # баланс (бесплатно)
tools/polza/polza models --type image --limit 10        # модели по возрастанию цены (бесплатно)
tools/polza/polza price <model> --param aspect_ratio=9:16   # цена и параметры (бесплатно)
tools/polza/polza gen <model> --prompt "..." --param aspect_ratio=9:16          # пробный прогон: только цена
tools/polza/polza gen <model> --prompt "..." --param aspect_ratio=9:16 --yes    # ПЛАТНО
tools/polza/polza status <id>                           # статус задачи
```

Типы для `--type`: `image`, `video`, `tts`, `music`, `stt`. Для image-to-image: `--image путь_или_url` (можно несколько).

## Правила денег (обязательно)

1. Перед любой платной генерацией: `balance`, затем `gen` БЕЗ `--yes` — показать пользователю модель, параметры и цену в ₽.
2. Запускать с `--yes` только после явного «да» пользователя на эту конкретную генерацию. Согласие не переносится на следующие генерации.
3. Если в ТЗ нет модели — предложить самую дешёвую подходящую (`models --type ...`), для видео обязательно назвать цену: видео стоит в десятки раз дороже картинок.
4. Не запускать генерации пачкой и параллельно без явной просьбы.

## Результаты

- Файлы сохраняются в `generated/` (или `--out путь`), запись о каждой генерации (дата, модель, промпт, цена, файл) — в `generated/polza-log.jsonl`.
- Ссылки Polza живут 7 дней — файл скачивается сразу.
- Облачный контейнер временный: чтобы файл не пропал, закоммитить его или перенести в папку reels/.

## Связка с монтажом

Скилл `reels-montage` запрещает генерировать вставки без просьбы. Поэтому генерацию для ролика делать только по прямой команде пользователя («сгенерируй картинку…»), а результат класть в `reels/inserts/`.
