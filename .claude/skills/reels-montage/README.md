# reels-montage — инструкция для пользователя

Скилл Claude для монтажа разговорных reels в стиле maysoulme (1080×1920).

## Установка

- **В этом репозитории**: скилл уже лежит в `.claude/skills/reels-montage/` и подхватывается Claude Code автоматически.
- **Глобально (на все проекты)**: скопируйте папку `reels-montage` в `~/.claude/skills/`.

## Подготовка (один раз)

При первом запуске Claude создаст на Рабочем столе папку `reels/` с подпапками. Разложите файлы шаблона:

| Папка | Что положить |
|---|---|
| `library/` | полоски (`strip` в имени) и градиент (`gradient` в имени), мемы |
| `fonts/` | заголовочный condensed-шрифт, субтитровый sans, рукописный |
| `stickers/` | один PNG без фона — иконка у субтитров |
| `music/` | фоновые треки (mp3) |
| `sfx/` | звуки появления вставок (свуш, поп) |
| `context_assets/` | постоянные вставки для всех роликов |

## Каждый ролик

1. Сырое видео → `reels/input/`, вставки для этого ролика → `reels/inserts/`.
2. Напишите Claude, например:

```
Смонтируй ролик.
ХУК: Как я монтирую reels за 5 минут
КОДОВОЕ СЛОВО: монтаж
когда говорю про статистику — покажи скрин со статистикой
МУЗЫКА: lofi
ЦЕНЗУРА: деньги
```

3. Готовый файл появится в `reels/output/<тема>-final.mp4`, исходники переедут в `reels/done/`.
